# 旧案の提案資料

学生向け「しめきりボード」案のピッチ資料と、その表示に使う素材をまとめています。現行の商品案は、小規模事業者向け期限管理SaaS [KIGEN](../../simekiribo-do/README.md) です。

| ファイル | 役割 |
| --- | --- |
| [`pitch_slides.md`](pitch_slides.md) | Slidev 形式の編集用ピッチ資料 |
| [`presentation.html`](presentation.html) | ブラウザで開ける単一 HTML 版のプレゼンテーション |
| [`public/keyvisual.html`](public/keyvisual.html) | 表紙用キービジュアル |
| [`public/lp_hero.html`](public/lp_hero.html) | 解決策スライド用の LP ヒーロー |

## Slidev で確認する

このディレクトリで次を実行します。

```bash
npx @slidev/cli pitch_slides.md --open
```

企画検討の経緯は、[Stage 21 の作成記録](../workshop/stage21_pitch_deck.md)を参照してください。
