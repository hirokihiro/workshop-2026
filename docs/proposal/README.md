# 提案資料

現行の商品案は、大学生向け課題管理アプリ [KIGEN Campus](../../simekiribo-do/README.md) です。以下のKIGEN発表資料は、方向転換前の小規模事業者向け案です。

## 方向転換前の事業者向け案

| ファイル | 役割 |
| --- | --- |
| [`kigen_presentation.html`](kigen_presentation.html) | 10枚構成の発表用スライド |
| [`kigen_pitch_script.md`](kigen_pitch_script.md) | 5分用の台本と想定質問 |
| [`public/kigen-dashboard.png`](public/kigen-dashboard.png) | 現行アプリの画面素材 |

発表用HTMLは、左右矢印キーで移動し、`N`キーで発表者ノートを表示できます。

## 旧学生向け案

| ファイル | 役割 |

| [`pitch_slides.md`](pitch_slides.md) | 旧案のSlidev形式ピッチ資料 |

## Slidev で確認する

このディレクトリで次を実行します。

```bash
npx @slidev/cli pitch_slides.md --open
```

企画検討の経緯は、[Stage 21 の作成記録](../workshop/stage21_pitch_deck.md)を参照してください。
